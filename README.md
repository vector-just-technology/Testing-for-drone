## How to run
___The code is already set up, you need to add your special things in ``__main__`` in order to actually run the things and then unfortunately a import error happened and you can no longer use import to the files and get their class, you will need to copy+paste lines in order to get full functionallity___

Anyway, when running the GUI version ``BUGGY!`` you may find two versions, the first one is ALPHA, which has core features, and more buggy, the other one is a more refined version that fixed many issues.

## Autopilot warnings

Autopilot may not be reliable, and therefore it is not recommended in hi-stakes competetions.

## Integration warning

This was designed to be separate files for separate functions, lets say ``if you wanted to enable autopilot in the GUI version`` well that is impossible. ``unless you edit many things``

### Improper integration

An attempt was made to integrate them all, but that resulted in the drone doing unwanted things, like randomly turning autopilot on, and more. So that is why I stuck with the ``import...`` system to keep them separate yet united ``a little bit.``
